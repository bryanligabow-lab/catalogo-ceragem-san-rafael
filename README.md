# Catálogo Digital · CERAGEM San Rafael

Catálogo de sesiones y tratamientos de **CERAGEM San Rafael (Valle de los Chillos)**.
Página única, responsive y mobile-first, optimizada para compartir por WhatsApp.

## 🔧 Configurar el WhatsApp
Abre [`index.html`](index.html) y cambia **una sola línea** (cerca del final, en el `<script>`):

```js
const WHATSAPP = "5939XXXXXXXX"; // <-- tu número, con código país, sin "+" ni espacios
```

Mientras no esté configurado, el sitio muestra un aviso amarillo arriba.

## 🖼️ Fotos
Deja las fotos reales en `assets/productos/` y se reemplazan los íconos por imágenes.

## 📋 Contenido
La fuente de verdad de todos los textos y precios está en [`contenido.md`](contenido.md).
